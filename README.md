# 📦 sing-box-extended Installer

Интерактивный автоматический установщик и обновлятор [sing-box-extended](https://github.com/shtorm-7/sing-box-extended) для OpenWrt.

## ✨ Возможности

- 🔄 **Интерактивный выбор** — скачивает список 3 последних стабильных версий и предлагает выбрать нужную.
- 📦 **Поддержка пакетов (.ipk / .apk)** — автоматически распознает пакетный менеджер (opkg/apk) и устанавливает пакеты для правильной системной интеграции (если они доступны для вашей архитектуры).
- 🗜 **Экономия места** — по умолчанию ищет и устанавливает `-compressed` версии (со сжатием UPX), экономя драгоценное место на флеш-памяти роутера.
- 🧠 **Умная распаковка** — анализирует свободное место в ОЗУ (`/tmp`) и на флеш-диске. Бережёт память и защищает роутер от зависаний (OOM) при нехватке места.
- 🏗 **Мультиархитектура** — поддержка ARM, x86, MIPS, RISC-V и других платформ с автоматическим фоллбэком на классический `.tar.gz`, если пакеты недоступны.
- 🛡 **Обход лимитов API** — делает всего 1 запрос к GitHub API, имеет встроенный скрытый токен и механизм запроса личного токена в случае бана по IP или исчерпания лимитов.

## 🚀 Использование

### Однострочная установка

```sh
sh <(wget -qO- https://raw.githubusercontent.com/EikeiDev/OpenWRT-sing-box-extended/refs/heads/main/install.sh)
```

Или через `curl`:

```sh
sh <(curl -sSL https://raw.githubusercontent.com/EikeiDev/OpenWRT-sing-box-extended/refs/heads/main/install.sh)
```

### Ручной запуск

```sh
wget -O install.sh https://raw.githubusercontent.com/EikeiDev/OpenWRT-sing-box-extended/refs/heads/main/install.sh
sh install.sh
```

## 🖥 Поддерживаемые архитектуры

| Архитектура | Платформы |
|---|---|
| `aarch64` | Raspberry Pi 4/5, Xiaomi, современные роутеры |
| `armv7` / `armv6` | Raspberry Pi 1-3, старые роутеры |
| `x86_64` | ПК, виртуальные машины, серверы |
| `i386 / i686` | Старые x86 системы |
| `mips / mipsel / mips64` | TP-Link, Xiaomi, Netgear (старые модели) |
| `riscv64` | RISC-V платы |
| `s390x` | IBM zSeries |

## ⚙️ Требования

- OpenWrt (или любой другой Linux-дистрибутив)
- `wget` или `curl`
- Доступ в интернет
